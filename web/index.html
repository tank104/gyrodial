Gyrodial

A round dial for your desk. Turn it for volume, flip it to a trackpad, talk to Claude, approve Claude Code.

  1. Get the board. A Waveshare ESP32-S3-Touch-AMOLED-1.75C. Nothing to solder.

  2. Install the firmware. Plug the board into this PC with a USB-C data cable, then click Install and pick the port named USB JTAG/serial debug unit.

    This browser can't talk to USB devices. Use Chrome or Edge. Installing needs https (or localhost).

    If it can't connect, hold BOOT while plugging the board in, then try again.

  3. Install the Gyrodial app. Download Gyrodial-Setup and run it. The app finds the dial over USB or Bluetooth. To pair, turn the dial to each number it shows and tap.

The firmware runs on ESP32-S3; the app needs Windows 10 (2004) or later. Open source on GitHub.
